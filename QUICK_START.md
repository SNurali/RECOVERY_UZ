## 🐛 Возможные проблемы

### Проблема: Старая версия страницы в браузере

**Решение:**
```bash
# Очистить кеш браузера
Ctrl + Shift + R (Chrome/Firefox)
Cmd + Shift + R (Mac)

# Или открыть в режиме инкогнито
Ctrl + Shift + N (Chrome)
Ctrl + Shift + P (Firefox)
```

### Проблема: Ошибки TypeScript при сборке

**Решение:**
```bash
# Проверить версию TypeScript
npm list typescript

# Переустановить зависимости
rm -rf node_modules package-lock.json
npm install
```

### Проблема: Не работает на production сервере

**Решение:**
```bash
# Проверить логи PM2
pm2 logs recovery-web --lines 50
pm2 logs recovery-api --lines 50

# Проверить Nginx
sudo nginx -t
sudo systemctl status nginx

# Проверить что dist/ обновился
ls -lh /home/yoyo/RECOVERY_UZ/dist/assets/GuestView*.js
```
