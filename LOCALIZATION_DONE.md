## 🚀 Как использовать

### Запуск приложения

```bash
# Backend (порт 3004)
node server.js

# Frontend (порт 3003)
npm run dev -- --port 3003

# Или всё вместе
npm run dev:all
```

### Тестирование

1. Откройте http://localhost:3003
2. Найдите переключатель языка (флаг) в правом верхнем углу
3. Нажмите на него и выберите язык
4. Все тексты изменятся мгновенно
5. Перезагрузите страницу - язык сохранится

## 📝 Использование в коде

```tsx
import { useI18n } from '../i18n/provider';

function MyComponent() {
  const { t, language, setLanguage } = useI18n();
  
  return (
    <div>
      <h1>{t('common.dashboard')}</h1>
      <button onClick={() => setLanguage('uz-lat')}>
        O'zbekcha
      </button>
    </div>
  );
}
```
