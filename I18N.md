# Система локализации RECOVERY.UZ

## ✅ Реализовано

### 1. Поддержка языков
- 🇷🇺 **Русский** (ru)
- 🇺🇿 **O'zbekcha** (uz-lat) - Латиница
- 🇺🇿 **Ўзбекча** (uz-cyr) - Кириллица
- 🇬🇧 **English** (en)

### 2. Компоненты

#### I18nProvider (`src/i18n/provider.tsx`)
- Context для управления языком
- Функция `t()` для перевода текстов
- Автоматическое сохранение выбранного языка в localStorage
- Поддержка параметров в переводах: `t('key', { param: 'value' })`

#### LanguageSwitcher (`src/components/LanguageSwitcher.tsx`)
- Выпадающий список с флагами стран
- Анимация открытия/закрытия
- Индикация текущего выбранного языка
- Автоматическое закрытие при клике вне компонента

## Использование

### Базовое использование

```tsx
import { useI18n } from '../i18n/provider';

function MyComponent() {
  const { t, language, setLanguage } = useI18n();
  
  return (
    <div>
      <h1>{t('common.dashboard')}</h1>
      <p>{t('auth.login')}</p>
    </div>
  );
}
```

### С параметрами

```tsx
// В JSON файле:
{
  "message": "Привет, {{name}}!"
}

// В компоненте:
t('message', { name: 'Иван' })
// Результат: "Привет, Иван!"
```

### Смена языка программно

```tsx
const { setLanguage } = useI18n();

// Сменить на узбекский (латиница)
setLanguage('uz-lat');

// Сменить на английский
setLanguage('en');
```

## Добавление новых переводов

1. Откройте все 4 файла переводов:
   - `src/i18n/ru.json`
   - `src/i18n/uz-lat.json`
   - `src/i18n/uz-cyr.json`
   - `src/i18n/en.json`

2. Добавьте новый ключ в каждый файл:

```json
{
  "mySection": {
    "newKey": "Новый текст"
  }
}
```

3. Используйте в компоненте:

```tsx
{t('mySection.newKey')}
```

## Расширение

Для добавления нового языка:

1. Создайте файл `src/i18n/новый-язык.json`
2. Добавьте импорт в `provider.tsx`:
```tsx
import newLang from './новый-язык.json';
```

3. Добавьте в объект translations:
```tsx
const translations = {
  'ru': ru,
  'новый-код': newLang
};
```

4. Обновите тип Language:
```tsx
export type Language = 'ru' | 'en' | 'uz-cyr' | 'uz-lat' | 'новый-код';
```

5. Добавьте в массив LANGUAGES в LanguageSwitcher:
```tsx
{ code: 'новый-код', label: 'Название', flagUrl: 'https://flagcdn.com/w40/код.png' }
```

## Производительность

- Переводы загружаются один раз при старте приложения
- Смена языка происходит мгновенно (без перезагрузки)
- Выбранный язык сохраняется в localStorage
- Нет дополнительных HTTP запросов
